# Utility 운전일지 — Google Apps Script 시연판

계정 없는 점검자도 휴대폰으로 링크만 열어 입력할 수 있습니다. 데이터는 관리자의 Google 시트에 저장됩니다. 비용은 0원입니다.

## 파일

| 파일 | 내용 |
|---|---|
| `Code.gs` | 웹앱 진입점, 시트 읽기/쓰기, API, `setup()` |
| `Logic.gs` | SPEC 판정, 입력 검증, 공기압축기 가동률 계산 (기존 엑셀 규칙 이식) |
| `Seed.gs` | 초기 데이터: 운전일지 점검항목 379개, 압축기 13대 설정, 기존 엑셀 측정값 52건 |
| `Index.html` | 모바일 화면 (점검 입력 / 오늘 현황 / 공기압축기) |
| `appsscript.json` | 시간대(Asia/Seoul)와 웹앱 공개 설정 (선택) |

## 설치 (약 10분)

1. Google 드라이브에서 **새 Google 시트**를 만듭니다. 이름은 예를 들어 `Utility 운전일지 DB`로 합니다.
2. 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본으로 있는 `Code.gs` 내용을 지우고 이 폴더의 `Code.gs` 내용을 붙여넣습니다.
4. 왼쪽 `+` 버튼으로 다음 파일을 추가하고 각각 붙여넣습니다.
   - **스크립트**: `Logic`, `Seed`
   - **HTML**: `Index`
5. (선택) ⚙️ 프로젝트 설정에서 "appsscript.json 매니페스트 파일 표시"를 켜고 `appsscript.json` 내용으로 바꿉니다. 시간대가 서울로 고정됩니다.
6. 상단 함수 선택 상자에서 **`setup`**을 고르고 **실행**을 누릅니다.
   - 처음 실행하면 권한 승인 창이 뜹니다. "고급 → (안전하지 않음)으로 이동"을 눌러 허용합니다. 본인이 만든 스크립트라서 뜨는 경고입니다.
   - 시트에 `점검항목` / `압축기설정` / `점검기록` 탭 3개가 생깁니다.
7. **배포 → 새 배포 → 유형: 웹 앱**을 선택합니다.
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
8. 생성된 `https://script.google.com/macros/s/.../exec` 주소를 점검자에게 공유합니다. 기본 PIN은 **1234**입니다.

## 운영 방법

- **PIN 변경:** 프로젝트 설정 → 스크립트 속성 → `PIN` 값을 수정합니다.
- **점검항목 추가·수정:** `점검항목` 시트에서 행을 추가하거나 SPEC(하한/상한)을 바꾸면 화면에 바로 반영됩니다.
  - `입력형태`는 `숫자` 또는 `선택`입니다.
  - `선택` 항목은 `선택지`와 `정상값`을 쉼표로 구분해 적습니다.
- **잘못 입력한 값:** 같은 날 같은 설비를 다시 저장하면 덮어씁니다(수정). 관리자는 `점검기록` 시트에서 직접 고쳐도 됩니다.
- **QR 바로가기:** 웹앱 주소 뒤에 `?campus=2캠퍼스&equip=공기압축기 1-1`을 붙이면 해당 설비 입력 화면이 바로 열립니다.
- **코드 수정 후:** 배포 → 배포 관리 → 편집 → 버전 "새 버전"으로 다시 배포해야 반영됩니다.

## 알아둘 점

- 무료 Gmail 계정으로 배포하면 화면 상단에 "Google Apps Script 사용자가 만든 앱" 안내 문구가 나옵니다.
- 점검기록은 하루 약 380행씩 늘어납니다. 1년이면 약 14만 행으로 Google 시트 한도(1천만 셀) 안이지만, 현황 화면이 점점 느려질 수 있습니다. 1년 단위로 기록 시트를 보관용으로 분리하는 것을 권장합니다.
- PIN은 외부인의 단순 접근을 막는 수준입니다. 링크와 PIN이 함께 유출되면 누구나 입력할 수 있습니다.
